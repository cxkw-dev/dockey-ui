# Dockey 0.1.4 — close to hide

- Closing the main window or using ⌘W hides it while Dockey keeps running. Reopen it from the Dock or the menu bar's **Show Dockey** item.
- The menu bar provides **Show Dockey** and **Quit Dockey**. Dockey's ⌘Q command, Quit Dockey, and Dock Quit end the application.
- The matte charcoal Dock icon has a brighter teal rim and halo. The sidebar mascot remains flat.

**Quit Dockey before installing an update or uninstalling it.** Use ⌘Q while Dockey is active, **Quit Dockey** from its menu bar item, or Dock → Quit. The red close button now only hides the window. Quitting leaves Docker Engine and existing containers running.

Includes the service artwork and AI Focus alignment from [0.1.3](https://github.com/cxkw-dev/dockey-ui/releases/tag/v0.1.3). Choose the `arm64` or `x86_64` ZIP for your Mac and verify its matching SHA-256 file. Requires macOS 14 or later and an existing local Docker CLI and engine. These alpha builds remain ad-hoc signed, not Developer ID signed or notarized; see the [installation guide](https://github.com/cxkw-dev/dockey-ui/blob/main/docs/install.md).

CI checks both architectures' tests, installation/archive behavior, startup, and bundled resources. Apple Silicon also renders the native demo. Intel hosted CI uses an explicit resources-only gate; physical Intel graphical compatibility remains unverified.
