# Dockey 0.1.5 — script wordmark and teal mascot outline

The mascot inside Dockey now shares the Dock icon's pale teal outline. It appears in the sidebar, About, and empty states, with a slightly stronger line at small sizes. The in-app character stays flat; the Dock retains its static glow.

The sidebar and About use a flat, connected script wordmark, rendered as cached native vectors in the current foreground color. Interface text and the small window title remain Geist. Lettering sources, notices, and offline regeneration instructions are included in the repository.

Includes the close-to-hide behavior and menu bar controls from [0.1.4](https://github.com/cxkw-dev/dockey-ui/releases/tag/v0.1.4). **Quit Dockey before updating** using ⌘Q, the menu bar's Quit Dockey item, or Dock → Quit; closing the window only hides it.

Choose the `arm64` or `x86_64` ZIP for your Mac and verify its matching SHA-256 file. Requires macOS 14 or later and an existing local Docker CLI and engine. Alpha builds remain ad-hoc signed, not Developer ID signed or notarized; see the [installation guide](https://github.com/cxkw-dev/dockey-ui/blob/main/docs/install.md). Apple Silicon CI verifies native rendering; Intel CI verifies startup and resources, with physical Intel graphical compatibility still unverified.
