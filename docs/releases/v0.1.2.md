# Dockey 0.1.2 — service icons and reliability

This native alpha updates service identification with recognizable, borderless monochrome artwork.

- Official ClickHouse, Langfuse, and Temporal marks, with verified image repository matching.
- MongoDB's standalone leaf, without the document backdrop.
- A full-body Lucide elephant for PostgreSQL, with its ISC license.
- AI Focus's existing F mark, without its yellow tile.
- Consistent icon slots with balanced visual sizes; smaller ClickHouse bars.
- Light and dark logo variants, loaded once and cached locally.
- Bundled upstream licenses and pinned asset provenance for the public source and app archives.
- Explicit loading, error, retry, and stale-data states for inspection, resource lists, and log streams.
- Paused and restarting containers remain visible when stopped containers are hidden.
- Resource caches resynchronize after a Docker event-stream connection gap.
- Event consumption continues during resynchronization, preventing a slow read from filling the event buffer.
- Image ID copying uses the real engine ID while preserving separate rows for multiple tags.
- Inspection redacts opaque label and driver-option values; its sharing guidance describes the limits of redaction.
- Switching detail tabs preserves the log session instead of restarting it.

Download the ZIP for your Mac (`arm64` for Apple Silicon, `x86_64` for Intel) and its matching SHA-256 file. Verify the checksum, extract, quit Dockey, and replace the installed app. Updating or uninstalling Dockey leaves Docker and its resources in place. See the [installation guide](https://github.com/cxkw-dev/dockey-ui/blob/main/docs/install.md).

Requires macOS 14 or later and an independently installed Docker CLI and local engine. These alpha builds are ad-hoc signed; they are not Developer ID signed or notarized. CI verifies both architectures' tests and bundle resources, including the service marks and license texts. Apple Silicon also runs native demo rendering. Intel's hosted runner uses an explicit resources-only gate because its Metal device fails to render windows; physical Intel graphical compatibility remains unverified.

This release retains the event-driven container updates, visible-only streaming metrics, grouped controls, logs, resource browsing, and app-local context selection introduced in the previous alpha. It does not bundle a Docker engine or VM.
