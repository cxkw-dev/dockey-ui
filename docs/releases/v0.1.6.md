# Dockey 0.1.6 — Rounded 01 wordmark

The sidebar and About use the selected **Rounded 01** lettering as project vector artwork, with the teal-outlined mascot. A shared brand component aligns the lettering's filled-area optical center; the About version remains separately below it.

The approved cropped reference, editable outline, provenance, and offline conversion tools are retained in the repository. The app draws cached native vectors without loading a wordmark image or font at runtime. Geist remains the interface typeface.

Native dark/light previews, installed-app checks, all 75 Swift tests, installation/archive checks, and both resource-bundle launch checks passed locally. Updated README artwork, demo screenshots, and the [verification record](https://github.com/cxkw-dev/dockey-ui/blob/main/docs/verification.md) accompany the release.

Requires macOS 14 or later and an existing local Docker CLI and engine. Choose the `arm64` or `x86_64` ZIP and verify its matching SHA-256 file. Quit Dockey before replacing it: use ⌘Q while it is active, **Quit Dockey**, or Dock → Quit; closing the window only hides it. These alpha builds are ad-hoc signed, not Developer ID signed or notarized. See the [installation guide](https://github.com/cxkw-dev/dockey-ui/blob/main/docs/install.md).

CI checks both architectures' tests and bundled resources. Apple Silicon also renders the native demo; Intel hosted CI uses an explicit resources-only gate. Physical Intel graphical compatibility remains unverified.
