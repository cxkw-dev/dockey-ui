# Dockey 0.1.3 — AI Focus alignment

Reduced AI Focus's tightly cropped F mark from 22 to 18 points and adjusted its optical position within the unchanged row slot. This brings its visible height and weight closer to the other service icons in both appearances.

Includes the service marks and reliability fixes from [0.1.2](https://github.com/cxkw-dev/dockey-ui/releases/tag/v0.1.2). Download the ZIP for your Mac (`arm64` or `x86_64`) and verify its matching SHA-256 file before replacing the app. Requires macOS 14 or later and an existing local Docker CLI and engine. These alpha builds are ad-hoc signed, not Developer ID signed or notarized; [installation details](https://github.com/cxkw-dev/dockey-ui/blob/main/docs/install.md) describe source builds and Gatekeeper limits.

CI checks both architectures' tests, installation and archive behavior, startup, and bundled resources. Apple Silicon also renders the native demo. Intel hosted CI uses an explicit resources-only gate; physical Intel graphical compatibility remains unverified.
